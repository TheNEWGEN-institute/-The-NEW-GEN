จัดการ Pop-up แคมเปญหน้าแรก (โครงการติวฟรี & ประกาศสำคัญ)

Pop-up จะเด้งขึ้นมากลางจอเมื่อมีคนเข้าหน้าแรกของเว็บไซต์ และเมื่อกดปิดจะมีแท็บมินิด้านข้างให้คลิกเปิดใหม่ได้
สถานะการแสดง Pop-up บนหน้าแรก เลือกเปิดใช้งานเพื่อเด้งให้ผู้เข้าชมเห็น หรือเลือกซ่อนไว้เมื่อหมดแคมเปญ
รองรับไฟล์ภาพ JPG, PNG, WEBP (แนะนำขนาดอัตราส่วน 16:9 หรือ 4:3 แนวนอน หรือภาพสี่เหลี่ยมจัตุรัส)
ป้ายนี้จะลอยอยู่ที่มุมซ้ายล่าง เพื่อให้คนกดเปิด Pop-up ขึ้นมาดูซ้ำได้
กดแล้วจะเปิดฟอร์มสมัครเรียนออนไลน์ในเว็บทันที บันทึกลงระบบหลังบ้าน
ตั้งค่าการอัปโหลดรูปภาพของนักเรียน (ตอนสมัครโครงการติวฟรี)
ข้อความนี้จะแสดงเป็นชื่อหัวข้อของช่องอัปโหลดรูปภาพในหน้าต่างสมัครของนักเรียน
จัดการรายวิชาในโครงการติวฟรี (ที่ให้นักเรียนเลือกสมัคร)
คุณสามารถเพิ่ม ลบ หรือแก้ไขวิชาที่เปิดให้ติวฟรี พร้อมระบุวันเวลาเรียน และคำอธิบายเนื้อหาได้ตามต้องการ

1. รีวิวจริงจากนักเรียน (จัดเรียงลำดับภาพได้)

2. โปสเตอร์ความสำเร็จของรุ่นพี่ & แกลเลอรีผลงาน (จัดเรียงลำดับภาพได้)

ลำดับ เรียง รูปโปสเตอร์ / ผลงาน ที่อยู่ไฟล์รูปภาพ (Image Path) จัดการ

ดาวน์โหลดไฟล์ข้อมูลสำรอง (Export JSON)

ดาวน์โหลดข้อมูลคอร์ส ติวเตอร์ รีวิว วิดีโอ และข้อมูลติดต่อทั้งหมดเก็บไว้เป็นไฟล์ JSON ในคอมพิวเตอร์

นำเข้าข้อมูลจากไฟล์สำรอง (Import JSON)

เลือกไฟล์ JSON ที่เคยบันทึกไว้เพื่อนำข้อมูลกลับมาใช้งาน

รีเซ็ตข้อมูลกลับสู่ค่าเริ่มต้นสถาบัน

ล้างการแก้ไขทั้งหมด และนำข้อมูลคอร์สและติวเตอร์ตั้งต้น 100% กลับมา

การล้างข้อมูลจะลบออกจาก Supabase จริง และกู้คืนไม่ได้
ทุกครั้งที่ล้าง ระบบจะแสดงรายการที่จะถูกลบให้ตรวจก่อน และดาวน์โหลดไฟล์สำรอง (JSON) ของส่วนที่ลบให้อัตโนมัติ — เก็บไฟล์ไว้ในเครื่อง ห้ามอัปขึ้น GitHub
